# Task 7 – Implement Module Imports and Standard Libraries

## 1. Using Python Modules
- Python allows reusing code through modules using the `import` keyword.
- For financial and precise arithmetic, the built-in `decimal` module is imported: `from decimal import Decimal`.

## 2. Standard Library Benefits
- Built-in libraries like `math`, `datetime`, and `decimal` save development time and prevent reinventing the wheel.
- `decimal.Decimal` avoids floating-point precision issues inherent in binary float representations.
